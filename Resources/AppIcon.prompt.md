# MonkShift app icon

Generated with the built-in ImageGen tool for this project. The PNG is the source
for the ICNS built by `scripts/build-icon.sh`; it is separate from the native
monochrome menu bar template. The generated square image was resized to 1024 px
with macOS `sips` for packaging. Transparent exterior margins are preserved.

## Final prompt

Use case: logo-brand. Asset type: final macOS 15 Sequoia desktop application icon for MonkShift, a quiet offline focus utility. Generate one polished square app-icon asset, not a presentation or mockup, at 1024 x 1024 or higher square resolution. Primary request: beautiful, stylish, Zen, minimalist, unmistakably at home among macOS 15 app icons. Subject: one small abstract Zen monk seated in the lotus pose, formed as a single smooth off-white ceramic sculpture with a round bald head, no face, no clothing ornament, no internal cutout details. Place the monk prominently in the center of a refined rounded-square charcoal stone tile, with generous balanced margins. Use the restrained tactile depth, soft bevel, subtle top-left lighting, delicate ambient shadow, and clean craftsmanship of macOS Big Sur through Sequoia app icons, not shiny liquid glass. The tile occupies about 82 percent of canvas width, with consistent large rounded corners and a genuinely transparent exterior margin. The figure should read clearly at 32 pixels; strong calm silhouette, no tiny details. Materials: matte porcelain against smooth graphite, subtle natural tonal variation, crisp edges. Front-facing orthographic view. Quiet and sophisticated, beautifully balanced. Constraints: exactly one icon, isolated on actual transparency outside the rounded tile; no text, letters, watermark, frame, grid, scenery, extra stones, bamboo, enso circle, interface, or drop-shadow background. Preserve transparent margin for native macOS Dock sizing.
